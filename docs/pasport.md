# Паспорт GLM-рецензента

Обновлено: 24.11.2026.

Роль: независимая проверка обезличенных проектов ответов, второй контур.

Репозиторий: `Askorbinka-1/glm-kontur`.

Порядок обмена: сервер публикует новые задачи в `inbox/`, GLM записывает JSON-вердикты в `verdicts/`, сервер забирает их в отдельную очередь `queue/verdicts-glm`.

Режим: пробный. Старые задачи не выгружались. Вердикты GLM не меняют статусы и не передаются в первый контур до проверки качества.

Проверено задач: 0.
