## Суть обращения (обезличено)

Проблема: кнопка паузы на руле работает, но кнопки «следующий/предыдущий трек» не переключают треки в сторонних медиаприложениях на головном устройстве.Причина установлена по системным логам и коду приложения:1. Нажатия кнопок руля принимает com.qinggan.keymanager.service и передаёт их перехватчику ru.mi.voyahstore (версия [ДАТА_1].1). Этот перехватчик специально предназначен для передачи команд текущему стороннему медиаприложению.2. ru.mi.voyahstore (класс service.KeyManager) пересылает команду через broadcast android.intent.action.MEDIA_BUTTON с setPackage(), причём только событие ACTION_DOWN.3. Современные медиаприложения на библиотеке AndroidX Media3 на Android 8+ через этот путь принимают только команду play, остальные отбрасывают. В логе приложения: «MediaButtonReceiver: Ignore key event that is not a 'play' command on API 26 or above». Поэтому пауза работает, а переключение треков нет.4. Если отправить команду через медиасессию, треки переключаются (проверено: KEYCODE_MEDIA_NEXT и KEYCODE_MEDIA_PREVIOUS через input keyevent).Решение для разработчиков: отправлять медиакнопки через AudioManager.dispatchMediaKeyEvent() (ACTION_DOWN + ACTION_UP) или MediaController.getTransportControls().skipToNext()/skipToPrevious() вместо broadcast MEDIA_BUTTON. Это изменение в несколько строк, и оно сделает кнопки руля рабочими для всех современных медиаприложений.Прошу передать обращение дистрибьютору или разработчикам ru.mi.voyahstore и сообщить, планируется ли исправление в обновлении.
